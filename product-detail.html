Personal / Not in production

TravelMind

Idea. Bring bus search, seat booking, payments, operator workflows, and traveler support into one application.

My contribution. I built the Angular and .NET application with PostgreSQL, microfrontends and microservices. It includes seat locking, payments, wallets, management and agent portals, analytics, and a mobile app. A LangGraph assistant supports booking and answers questions using retrieval from a knowledge base.

The personal build is feature complete, but is not currently running as a production service. Its integrations include RabbitMQ, Redis, Razorpay, Google APIs, Sentry, PostHog, and Google Analytics.
